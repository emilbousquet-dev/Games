# 100 Game Ideas 🎮💡

Ideas for new games to build in this repo. They all fit the way **LAB 13** is made:
they run in the browser by opening an `.html` file, use [three.js](https://threejs.org) (or plain 2D canvas),
draw their textures and make their sounds with code, and many can be played with a **friend in split screen**
or with controllers.

How hard each one is to build:
⭐ = a weekend · ⭐⭐ = a few weeks · ⭐⭐⭐ = a big project

♻️ = can reuse a lot of LAB 13 (the letter maps, the models, the sounds, split screen, flashlights...)

## 🏆 Best ones to start with

If you want to make one **right now**, these are fast to build and fun to play:

- **#100 Whack-an-Alien** and **#92 Pac-Lab** — reuse LAB 13's models and sounds, so they're mostly game rules.
- **#68 Sumo Blobs** — a great first split-screen game: just a round platform, physics, and pushing.
- **#47 Light Beams** — small puzzle game, easy to add levels to.
- **#46 Two Keys** — takes the best part of LAB 13 (2-person locks) and makes a whole game out of it.
- **#63 City from Letters** — the "draw a level with letters" trick from `js/map.js`, but for a whole city.

## 💡 Tips for making new games in this repo

- Make each game its own folder (like `sumo-blobs/index.html`) so you can just double-click to play.
- Copy `js/audio.js` to get free sound effects made with math, and `js/textures.js` for walls and floors.
- Copy `js/input.js` to get keyboard + controller support for two players.
- Use letters in a map for the levels, like `js/map.js`. That way anyone can make new levels.
